# Cloud-Native-Image-Recognition-System
"A highly scalable, microservices-based [Image/Face/Voice] recognition system built for the cloud. Featuring containerized AI models, automated scaling, and real-time inference via [Kubernetes/Docker]."

This project is a scalable microservices app for real- time object detection.It uses AWS S3 fot storage and AWS Lambda to trigger the recognition engine, reducing costs by 30% Orchestrated via Kubernetes to handle 40% traffic spikes.
